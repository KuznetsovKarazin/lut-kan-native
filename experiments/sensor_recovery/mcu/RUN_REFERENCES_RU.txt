ДОПОЛНИТЕЛЬНЫЙ ПАКЕТ: ЕДИНЫЙ НАБОР ШЕСТИ МОДЕЛЕЙ
8 ноября 2026 года

Назначение
В ранее сохранённых опытах полином и физическая модель уже измерены на Mega2560 и ESP32-C3. Повторять эти платы только для доказательства наличия baselines не требуется. Этот пакет переносит обе малые модели на более поздний matched-набор и позволяет добавить ESP32-S3 с FPU. Новых аппаратных результатов в статье пока нет. Сборка для всех трёх конфигураций прошла; это не измерение на плате.

Распакуйте ZIP в отдельную папку. Откройте PowerShell в её корне, где находится experiments. Скрипт загрузит новую тестовую прошивку, заменив текущую прошивку выбранной платы. Сохраните нужную прикладную прошивку заранее. Датчики подключать не нужно: тест использует сохранённые синтетические входы. Закройте Serial Monitor и другие программы, занимающие COM-порт.

Установка:
py -m pip install -r experiments\sensor_recovery\mcu\requirements.txt
py -m serial.tools.list_ports

Выберите только команду для подключённой платы. COM7 — пример; замените фактическим портом. Каждый запуск требует нового имени выходной папки.

Mega2560, 16 MHz:
py experiments\sensor_recovery\mcu\run_references.py --board mega2560 --port COM7 --out runs\mega_references_01 --runs 2

ESP32-C3, 160 MHz, плата/подключение как в прежних опытах:
py experiments\sensor_recovery\mcu\run_references.py --board esp32c3 --port COM7 --out runs\c3_references_01 --runs 2

Необязательный FPU-опыт: ESP32-S3-DevKitC-1, 240 MHz, USB–UART разъём/мост, не native USB. Эта конфигурация не означает совместимость с любой платой ESP32-S3; перед применением к иной модели нужно выбрать её board и проверить распиновку/память.
py experiments\sensor_recovery\mcu\run_references.py --board esp32s3 --port COM7 --out runs\s3_references_01 --runs 2

При первом запуске PlatformIO загружает инструменты; сборка может занять несколько минут. Скрипт сам делает одну загрузку и два тёплых сеанса, проверяет идентификатор входов, независимые session ID, полноту 70 записей времени и шесть проверок точности, затем упаковывает логи, JSON, хеши и образы прошивки.

Успешный итог: Validated 2 complete baseline captures. Board may be disconnected.
Для анализа нужен весь созданный ZIP рядом с папкой runs, а не только последняя строка. При ошибке сохраните полный ZIP с диагностикой; не используйте частичный результат как измерение. Пакет не измеряет энергию, WCET, реальную погрешность датчика или пик стека.
