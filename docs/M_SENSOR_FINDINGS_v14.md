# M_SENSOR_FINDINGS_v14.md — Multi-sensor calibration study (TIM v14)
## Date: 2026-04-25 | Version: v14.0

## Изменения относительно v13
1. **TypeK исправлен**: T_range=(0,350), V_bias=0.27 В — ADC строго монотонен
2. **TypeK результат**: poly preferred (ratio ~0.85×, ns) — EMF(T) гладкая, poly-5 даёт 0.04°C
3. LDR добавлен: ratio=2.38×, p=0.004 — сильный результат, **новый представитель LUT wins**
4. Новые baselines для NTC: SHH(50 noisy) и single-point offset
5. L sweep: L=8,16 проигрывают poly — подтверждение coverage rule
6. Задержка исправлена: **~80 мкс/вызов на AVR** (не 16 нс!)

## Итоговая классификация режимов (6 датчиков)

| Датчик | Физическая модель | poly/LUT | p | Режим |
|--------|-------------------|----------|---|-------|
| LDR фоторезистор | R = R₁₀·(10/E)^γ, логарифм | 2.38× | 0.004 ** | **LUT wins** |
| NTC термистор | R = R₀·exp(B/T), экспонента | 1.66× | 0.004 ** | **LUT wins** |
| Влажность | R = R₀·exp(-α·RH), экспонента | 1.60× | 0.008 ** | **LUT wins** |
| Термопара Type K | EMF(T) = NIST ITS-90 (гладкая) | ~0.85× | ns | **Poly preferred** |
| Газ MQ | Rs/R0 = A·C^(-B), степенная | 0.80× | ns | **Poly preferred** |
| pH электрод | E = E₀ + S·(7-pH), линейная | 0.47× | ns | **Poly preferred** |

**Ключевой вывод**: LUT выигрывает только для датчиков с нелинейными
(экспоненциальными или логарифмическими) кривыми ADC→physical.
TypeK подтверждает критерий с другой стороны: его EMF(T) хорошо
аппроксимируется полиномом степени 5, поэтому LUT не добавляет ценности.

## NTC: расширенное сравнение (6 методов × 8 единиц)

| Метод | Mean MAE (°C) | Примечание |
|-------|--------------|-----------|
| Factory | ~0.65 | Синтет. B~3950K; реальные данные (v13): 1.62°C |
| One-point offset | ~0.28 | factory poly + const сдвиг |
| Poly-5 | ~0.28 | degree-search 3-5 |
| SHH (3 ideal) | ~0.000 | Синт. данные: B восстанавлив. точно; реальные: 0.004°C |
| SHH (50 noisy) | ~0.039 | Честное сравнение: физ. prior всё равно лучше LUT |
| **LUT (K=1,L=32)** | **~0.169** | sensor-agnostic, 5 seeds |

ratio poly/LUT = 1.66×, p=0.004

## L sweep (NTC, K=1, N=50)

| L | MAE (°C) | vs poly | Bytes |
|---|----------|---------|-------|
| 8  | 2.019 | ХУЖЕ | 8  |
| 16 | 0.620 | ХУЖЕ | 16 |
| **32** | **0.174** | **LUT wins** | **32** |
| 64 | 0.089 | LUT wins | 64 |

**Вывод**: coverage rule K×L < N_cal необходима, но недостаточна.
При L=8,16: клеток мало для формы NTC-кривой даже при N=50.
Минимум L=32 при N=50 для победы над poly.
